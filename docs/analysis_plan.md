# Project analysis plan

## Objectives

- Evaluate water, soil, tree, and leaf metrics over a 4-year period
- Compare patterns across plots and years
- Identify long-term variation and relationships among study variables

## Data handling principles

- Preserve original raw files in `data/raw/`
- Standardize variable names and units prior to analysis
- Save cleaned files in `data/cleaned/`
- Use reproducible scripts and save outputs in `outputs/`

## Recommended workflow

1. Import raw data files
2. Clean and validate the data
3. Build annual summaries by plot and year
4. Generate figures and regression summaries
5. Record results in final report documents
